## Open Invitation for Independent Review

**Locked Gravitational Saturation Cosmology is publicly available for independent examination.**

This project investigates whether gravitational saturation could provide a common phenomenological explanation for effects normally attributed to dark matter on galactic scales and dark energy on cosmological scales.

This work is **not presented as established or independently confirmed physics**. The equations, computational implementation, tests, numerical results, manuscript, and reproducibility material are public so that others can examine them independently.

Physicists, cosmologists, astronomers, numerical researchers, scientific programmers, independent researchers, students, and technically capable skeptics are invited to examine the work.

### Try to break the model.

Check the equations. Run the code. Reproduce the calculations. Compare the results with observations. Look for hidden assumptions, numerical artifacts, or inconsistencies.

A successful independent reproduction would be valuable.

A clearly demonstrated failure would also be valuable.

**This is not a request for endorsement. It is an invitation for independent examination.**

— **James Lawrence, Independent Researcher**
