# Contributing and Technical Review

This repository is primarily a record for independent review rather than an open collaborative rewrite.

## Reporting an issue

Please use the appropriate issue template and include:

- manuscript page and section;
- equation, figure, or table number where applicable;
- a precise description of the suspected problem;
- a derivation, calculation, citation, or reproducible test supporting the concern; and
- whether the issue is editorial, mathematical, numerical, statistical, or interpretive.

Good-faith criticism, failed reproduction attempts, and negative results are welcome.

## Proposed corrections

Corrections should preserve a transparent record. Material changes to equations, parameter values, code, or reported results should be documented in the changelog and released as a new version rather than silently replacing the current review copy.
