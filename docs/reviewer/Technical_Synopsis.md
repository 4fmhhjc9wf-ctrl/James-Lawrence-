# Technical Synopsis

This is the browser-readable technical entry point for Locked Saturation Cosmology.

## Saturation response

The model uses a saturation variable `C` with

```text
μ(C) = 1 - C
```

and

```text
0 ≤ C < 1
```

## Stable residual potential

The current local representation is

```text
V(C) = V∞ + 1/2 m²(C - C*)²
```

subject to

```text
C* < 1
m² > 0
```

The condition `m² > 0` describes positive local curvature of the bare potential. Full perturbative stability remains a separate question for independent analysis.

## Cosmological freeze-out implementation

After freeze-out:

```text
H² = (8π G_eff / 3) (ρ_m + ρ_r + V∞)
```

where

```text
G_eff = G / μ*
μ* = 1 - C*
```

## Weak-field phenomenology

The currently used screened response is

```text
μ(x) = x / sqrt(1 + x²)
```

The scientific question is whether a compact gravitational-saturation framework can reproduce relevant behavior across gravitational regimes without requiring a separately adjustable mechanism for each scale.

Growth, sound-horizon behavior, the complete perturbation spectrum, lensing, and independent statistical comparison remain appropriate areas for further testing.
